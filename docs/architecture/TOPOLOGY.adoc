== Iseriser — Architectural Topology

=== Overview

Iseriser is the meta-framework that generates new -iser projects. It
takes a language description as input and produces a complete -iser
repository as output.

=== Data Flow

....
                      iseriser.toml
                    (language description)
                           |
                           v
                   +---------------+
                   | Manifest      |
                   | Parser        |
                   | (Rust/serde)  |
                   +---------------+
                           |
                           v
                   +---------------+
                   | Language       |
                   | Model          |
                   | (internal IR)  |
                   +---------------+
                      /    |    \
                     /     |     \
                    v      v      v
          +--------+ +--------+ +--------+
          | Idris2 | |Template| | RSR    |
          | ABI    | | Engine | | Gov.   |
          | Proofs | |(Hbars) | | Gen.   |
          +--------+ +--------+ +--------+
                \      |      /
                 \     |     /
                  v    v    v
            +------------------+
            | Generated -iser  |
            | Repository       |
            | (complete, ready |
            |  to cargo build) |
            +------------------+
....

=== Generation Pipeline

[arabic]
. *Parse* — `+iseriser.toml+` -> `+LanguageDescription+` struct
. *Model* — `+LanguageDescription+` -> `+LanguageModel+` (features,
targets, ABI shape)
. *Verify* — Idris2 ABI checks language model consistency
. *Expand* — Handlebars templates + language model -> file tree
. *Write* — file tree -> disk (complete -iser repo)
. *Validate* — generated repo passes `+cargo check+` and template
completeness
