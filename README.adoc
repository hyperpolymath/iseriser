== What Is This?

Iseriser is the **meta-framework** that generates new -iser projects.

Given a description of a target language's interop model (how it exposes
functions, its type system, its build process), Iseriser scaffolds a
complete -iser project with manifest parser, code generation engine,
Idris2 ABI definitions, and Zig FFI bridge.

== How It Works

Describe a target language in `iseriser.toml`. Iseriser:

1. Generates a complete -iser repo (Cargo.toml, src/, README, tests)
2. Scaffolds the manifest parser for the target language's concepts
3. Generates codegen templates for the target's interop model
4. Creates Idris2 ABI stubs appropriate to the target's type system
5. Creates Zig FFI bridge templates for the target's calling convention

== Key Value

* **Create a new -iser in minutes** instead of days
* **Consistent architecture** across all -iser projects
* **The -iser that makes -isers** — bootstrapping the ecosystem

== Architecture

Follows the hyperpolymath -iser pattern (same as https://github.com/hyperpolymath/chapeliser[Chapeliser]):

* **Manifest** (`iseriser.toml`) — describe WHAT you want
* **Idris2 ABI** (`src/abi/`) — formal proofs of interface correctness
* **Zig FFI** (`ffi/zig/`) — C-ABI bridge to target language runtime
* **Codegen** (`src/codegen/`) — generates target language wrapper code
* **Rust CLI** — parses manifest, validates, generates, builds, runs

User writes zero target language code. Iseriser generates everything.

Part of the https://github.com/hyperpolymath/iseriser[-iser family] of acceleration frameworks.
