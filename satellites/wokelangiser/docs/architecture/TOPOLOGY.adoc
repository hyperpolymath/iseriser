== Wokelangiser Topology

=== Overview

Wokelangiser transforms existing code into consent-aware, accessible,
internationalised, and culturally sensitive software by injecting
WokeLang decorator patterns at the source level. It follows the standard
hyperpolymath -iser architecture.

=== Consent State Machine

....
  Pending --GrantConsent--> Granted --ActivateConsent--> Active --RevokeActive--> Revoked
                               |                                                    ^
                               +----------RevokeGranted-----------------------------+
....

All transitions are encoded as `+ValidTransition+` proofs in
`+Types.idr+`. Invalid transitions (e.g. Pending -> Active, Revoked ->
anything) are rejected at the type level.

=== WCAG Contrast Thresholds

[cols=",,",options="header",]
|===
|Level |Minimum Ratio |Encoded Value
|A |none |0
|AA |4.5:1 |450
|AAA |7.0:1 |700
|===

Contrast ratio calculated using WCAG 2.2 relative luminance algorithm
(sRGB linearisation + weighted sum) in `+wokelangiser_contrast_ratio+`.
